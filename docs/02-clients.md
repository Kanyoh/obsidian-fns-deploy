# 02 · 客户端配置（Windows / macOS / Android / iPad / iPhone）

目标：所有设备连**同一个服务端、同一个账号、同一个远端笔记库名**，实时同步。

---

## 1. 先选一个"所有设备都能访问"的地址

服务端装在公司电脑上，不同设备所处的网络不一样，所以插件里的「远端服务地址」要选**一个全设备通用**的：

| 场景 | 地址示例 | 说明 |
|---|---|---|
| 只在家里/公司同一局域网 | `http://192.168.1.23:9000` | 最简单，但出门/移动网络不可用 |
| **推荐：Tailscale** | `https://fns-pc.tailxxxx.ts.net`（`tailscale serve`）或 `http://100.101.102.103:9000` | 所有设备装 Tailscale 后可用，加密 |
| Cloudflare Tunnel | `https://fns.example.com` | 需要域名/Cloudflare 账号 |
| 公网 IP + 端口映射 | `https://notes.example.com` | 公司网络通常不允许 |

> **建议所有设备统一填同一个地址**（例如 Tailscale 的 HTTPS 地址），不要有的填局域网、有的填公网，否则换网络时容易连不上。
> Tailscale 配置见 `03-remote-access-tailscale.md`。

---

## 2. 安装插件

### 方式 A：社区商店（推荐）

Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 浏览 → 搜索 **Fast Note Sync** → 安装 → 启用。

### 方式 B：手动安装（商店打不开 / 公司网络受限）

1. 关闭 Obsidian；
2. 在 vault 下创建：

```
<你的库>/.obsidian/plugins/fast-note-sync/
```

3. 放入三个文件（从 [Releases](https://github.com/haierkeys/obsidian-fast-note-sync/releases) 下载，版本 2.4.0）：

```
main.js
manifest.json
styles.css
```

4. 打开 Obsidian → 设置 → 第三方插件 → 启用 **Fast Note Sync**。

> 插件要求 **Obsidian ≥ 1.8.7**；移动端同样支持（`isDesktopOnly: false`）。

---

## 3. 填入服务端配置

打开 设置 → **Fast Note Sync** → 「远端」：

| 设置项 | 填什么 |
|---|---|
| 远端服务地址 | `https://fns-pc.tailxxxx.ts.net`（不带 `/api`，结尾不要斜杠） |
| 远端授权令牌 | 服务端「复制 API 配置」里的 `apiToken` |
| 远端笔记库名 | 所有设备统一，例如 `main` |
| 客户端名称 | `PC-公司` / `PC-家里` / `iPad` / `手机` |

**最快方式**：服务端 Web UI →「笔记库」→「复制 API 配置」，回到插件点「**粘贴服务端授权配置**」。

连接成功后应显示「服务已连接」以及账号 / UID。

---

## 4. 首次同步顺序（很重要）

```
① 服务端空库
   ↓
② 公司 PC（内容最全）连接 → 全量上传 → Web UI 确认笔记数量正确
   ↓
③ 家里 PC 用空库连接 → 全量下载
   ↓
④ 平板 / 手机用空库连接 → 全量下载
   ↓
⑤ 稳定 1~3 天后再考虑开启"配置项同步"
```

不要做的事：

- 两台都有内容、直接互相同步（会冲突/覆盖）；
- 先连空库设备再连主设备；
- 多台同时首次全量上传。

> 如果家里 PC 已有旧笔记：先备份整个 vault，再把旧笔记**复制进**新库，让插件逐篇上传。

---

## 5. 推荐设置（首轮）

| 设置 | 建议 | 原因 |
|---|---|---|
| 笔记和附件同步 | ✅ 开 | 核心功能 |
| 配置项同步 | ❌ 先关 | 跨平台插件差异容易出问题；稳定后再开 |
| PDF 状态同步 | 可关 | 依赖配置同步 |
| 冲突合并策略 | **手动合并**（或"最新才合并"） | 多端同时改时不至于静默丢内容 |
| 离线删除同步 | ✅ 开 | 离线删的笔记重连后一致 |
| 手动同步模式 | ❌ 关 | 否则不会自动同步 |
| 只读同步模式 | ❌ 关 | 只有展示机才开 |
| 附件同步大小限制 | ✅ 开，20–30 MB | 手机端防 OOM |
| 笔记同步最大限制 | 20 MB（默认） | 足够 |

### 同步排除（建议直接加）

```
.git/
.trash/
.obsidian/workspace.json
.obsidian/workspace-mobile.json
*.tmp
*.log
```

> 如果 vault 里用了 **obsidian-git**，务必排除 `.git/`，否则会把 Git 对象当附件同步、还可能与自动提交打架。

### 关于「配置项同步」

开启后会用服务端配置**覆盖本地**（首次）。建议：

- 所有设备装好同名插件后再开；
- 排除 `workspace*.json`、以及各插件差异较大的 `data.json`；
- 出问题就关掉，配置同步不是必需品。

## 6. 移动端注意事项

| 平台 | 要点 |
|---|---|
| Android | 给 Obsidian 关闭电池优化；库放 `Documents/Obsidian/...`；切后台后同步会暂停 |
| iOS / iPadOS | 系统限制后台，**打开 Obsidian 才同步**；库放"我的 iPhone/iPad"或 iCloud Drive |
| 移动端首次 | 建议 Wi-Fi 下完成首次全量下载 |
| 存储 | 大附件可配合"附件云预览"或排除规则，避免占满手机 |

手机端「手机端失焦延迟暂停同步」保持默认即可（切走 30 秒后暂停，省电）。

---

## 7. 验收

| # | 检查 | 通过标准 |
|---|---|---|
| 1 | 插件状态 | 显示"服务已连接" + 账号/UID |
| 2 | 服务端笔记数 | 与主设备一致 |
| 3 | PC ↔ PC | A 改一篇，B 几秒内出现 |
| 4 | PC ↔ 平板 | 平板改，回 PC 可见 |
| 5 | 删除 | PC 删除，平板消失/进回收站 |
| 6 | 离线编辑 | 断网改，恢复后按策略合并 |
| 7 | 重启服务端 | 客户端自动重连 |

---

## 8. 常见问题

- **连不上**：先在设备浏览器打开 `apiUrl`，能出登录页说明网络通；不通查 Tailscale/防火墙。
- **401 / 令牌无效**：服务端重新「复制 API 配置」，确认 `auth-token-key` 没被改过。
- **连上但不同步**：检查三端「远端笔记库名」是否一致、是否开了只读/手动模式。
- **冲突多**：改"手动合并"，避免同一篇双端同时编辑。
